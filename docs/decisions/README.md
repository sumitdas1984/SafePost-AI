# Architecture Decision Records

Record important decisions here.

Suggested format:

```text
ADR-001 — Dataset Selection
ADR-002 — BiLSTM vs Transformer
ADR-003 — SageMaker Real-Time Endpoint
ADR-004 — ECS/Fargate Application Hosting
ADR-005 — Terraform
```

Keep each decision short:
- Context
- Decision
- Alternatives considered
- Consequences
